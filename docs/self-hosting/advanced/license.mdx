The **Formbricks AGPL fork** is licensed entirely under [AGPLv3](https://github.com/formbricks/formbricks/blob/main/LICENSE).

## Licensing Model

This fork differs from upstream Formbricks:

- The upstream Formbricks core is licensed under AGPLv3, but the `apps/web/modules/ee` directory is licensed under a separate, **paid** Enterprise License.
- In this fork, **all content under `apps/web/modules/ee/` has been rewritten from scratch** as original AGPLv3 code. There is no separate enterprise license and no proprietary code.
- The `apps/web/modules/ee/LICENSE` file does not exist in this fork.
