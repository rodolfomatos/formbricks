This is the **AGPL fork** of Formbricks. Enterprise Edition gates have been removed entirely. Every feature is available without a license key.

## No License Key Needed

- The enterprise license environment variable has been **removed entirely** in this fork (it no longer exists in `.env.example`, the Helm chart, or the Docker compose file).
- There are **no license gates** — all features are always enabled.
- There is **no phone-home** to `ee.formbricks.com`. No license checks are performed, and no daily network call to Formbricks occurs.

## What This Means For Your Deployment

1. **Skip license activation** — there is nothing to activate.
2. **No firewall exceptions** — you do not need to whitelist `ee.formbricks.com` or any external license server.
3. **No grace periods** — there is no license that can expire or be revoked.

## Features That Were Enterprise-Only Upstream

The following features are unlocked and always available in this fork:

- Audit logging
- Contacts + Segments
- Teams and role management
- Response quotas
- White-labeling (remove branding, custom email/favicon)
- Analysis dashboards
- SAML 2.0 SSO
- TOTP two-factor authentication
- AI translation (add your own AI API key)
- Unify feedback + feedback directories

## Legal Note

All Enterprise Edition features have been **rewritten from scratch** as original AGPLv3 code. No proprietary Formbricks enterprise source code is used in `apps/web/modules/ee/`. See the root `LICENSE` file for details.
