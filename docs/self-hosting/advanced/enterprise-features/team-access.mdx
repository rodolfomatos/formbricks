title: "Teams & Roles (RBAC)"
description: "Granularly control which users have access to specific Workspaces and surveys."
icon: "user"
---

Each User can be a member of any number of Teams.

Each Team can have Read, Write or Manage access to any number of Workspaces.

In this AGPL fork, you can granularly assign Roles and Memberships to users (upstream: Enterprise Edition feature).

Here are [all details of user management](https://formbricks.com/docs/xm-and-surveys/core-features/user-management#memberships)
